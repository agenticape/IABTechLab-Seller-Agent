What you're watching
  • On the left, a buyer agent (a script acting for a fictional advertiser) talks to a seller agent on the right: an IAB Tech Lab reference seller running mock inventory.
  • Each exchange is one real HTTP call to the seller's REST API: catalog discovery, tiered pricing, quotes, price negotiation and deal booking. The bubbles say in plain words what was asked and answered.
  • Green means the seller agreed, amber means it countered or held the request for a human, red means it refused (for example, writes with no API key). Click details for the raw JSON.
  • Bookings over $250,000 are held for human approval (HTTP 202). This page never approves them.
  • In the blocky 3D view, drag to turn the camera and scroll to zoom. Booked deals appear as gold blocks on the stall and approval holds as padlock blocks. The View button switches to the flat view.
